# Changelog

版本号三处联动：host `package.json` ↔ App `pubspec.yaml`（三段 = tag，build number 只增不减）↓ Release tag。App 版本号必须与 Gitee release tag 同步 bump，否则手机端会反复弹"发现新版本"。

## 1.1.3（未发布）

- **新增：前后置镜头切换（双端）**。手机端取景器右上角新增镜头切换按钮（单摄设备自动隐藏，切换中转圈）；电脑端新增模型工具 `phone_camera_lens`——`lens` 传 "front"/"back" 切换镜头，不带参数查询当前镜头与设备可用镜头（工具对相机关闭的手机同样可用：仅记录偏好，下次开启生效）。需手机端 ≥ 1.1.3，沿用三档失败判定。
- **精简：`phone_camera_zoom_info` 并入 `phone_camera_zoom`**——不带参数调用 zoom 即查询当前倍数与支持范围（手机端早已支持，纯工具层冗余）；工具总数 7→6。`phone_camera_pause`/`resume` 审查后保留独立（反义动作直命名对模型更清晰）。
- **修复：悬浮面板弹出方向左右反了**——球靠左时面板向左弹出被屏幕裁掉（水平侧判定与锚点类语义相反），现已按"空间大的一侧展开"正确选择。

- **悬浮球可拖拽、可调大小**：按住悬浮球可拖到屏幕任意位置（自动限制在视口内，窗口缩放后自动收回）；设置页新增"悬浮球"分组——三档大小、四角停靠（左上/右上/左下/右下）、锁定位置防误拖、一键恢复默认。取景面板/重命名/下载码弹层会根据悬浮球位置与面板实际高度智能选择弹出方向（上下左右四向），弹出动效随之适配。
- **保存文件夹改为浏览选择**：拍照模式选"注入并保存/仅保存"后，目录输入旁新增"浏览…"按钮，弹出资源管理器式文件夹选择框（上级/主目录/盘符切换、逐级进入、选完即存）。手输/粘贴路径仍然可用。浏览器网页拿不到系统目录选择对话框的绝对路径，故由接收端（loopback 专属接口）遍历目录树提供。
- **设置页重构**：官方设置页（设置 → PhoneLens）整理为三张卡片——"模型相机工具"（启用/免确认开关 + 工具清单说明）、"悬浮球"、"连接"。接收端口从悬浮窗 ⚙ 面板移入设置页（保存即时生效，无需刷新）；悬浮窗 ⚙ 只保留高频的拍照模式与保存目录。
- **修复：变焦/暂停工具间歇误报"手机 App 版本过旧"**。手机 WS 重连后 host 端把相机元数据重置，而 App 版本只随预览流启动的 hello 上报——预览关闭或重连后的秒级窗口内，版本门槛读到空值，把正当版本的手机误判为过旧。现在失败原因分三档（没有已连接的手机 / 刚重连握手尚未完成 / 真版本不足），门槛检查前短暂等待（≤1 秒），App 端连接建立即上报版本（新 `app_info` 消息，不再绑定预览流启动）。
- **安全：HTTP 与 WebSocket 全面校验 Host 头（DNS rebinding 防护）**。合法客户端一律以 IP 字面量或 localhost 访问，域名形式或缺失的 Host 头一律 403 拒绝。
- 补齐 CHANGELOG（0.3.6 起此前全部缺失）。

## 1.1.2（2026-10-12）

- 模型变焦双工具：`phone_camera_zoom`（设定/步进）与 `phone_camera_zoom_info`（查询倍率与范围），直接驱动手机原生变焦。
- 修复：扫码配对成功后 socket 未即时重建（ValueKey 恒定导致不重连），现随 host/port/deviceId/token 变化自动 rebind。
- 三路并行审查后约 31 项修复，含上传队列体积膨胀三路径（孤儿文件、切模式清存量、failed 队列上限 20）。

## 1.1.1（2026-10-08）
