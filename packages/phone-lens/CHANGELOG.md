# Changelog

版本号三处联动：host `package.json` ↔ App `pubspec.yaml`（三段 = tag，build number 只增不减）↓ Release tag。App 版本号必须与 Gitee release tag 同步 bump，否则手机端会反复弹"发现新版本"。

## 1.1.5（2026-11-07）

- **新增：裁剪页精细编辑（App 端）**。画笔/马赛克模式下双指捏合缩放 + 拖动平移整幅画面（1x~6x，以双指中心为锚点），放大后可做精细标注；右上角出现「回原比例」小按钮一键复位。缩放只是视图变换，笔画/裁剪框数据全部保持在图像空间，导出结果与屏幕所见严格一致，与裁剪、画笔、马赛克、旋转互不干扰（旋转/翻页自动复位缩放）。
- **修复：双指缩放残留误触笔画点**。双指落下时自动清扫 600ms 内未延伸的单点笔画（缩放前每根手指的落点都会留下一个小点），有意画的单指点不受影响。
- **改进：次级工具栏可收起**。画笔/马赛克激活后再次点击主工具栏按钮收起参数面板（工具保持激活），不再遮挡画面编辑区域；切换到其他工具时自动重新展开。
- **改进：笔画大小改滑条连续调节 + 六色画笔**。三档圆点按钮换成滑条（画笔宽度约图像宽度 0.4%~8%、马赛克块 1%~12% 拖动即见），新增红/蓝/黄/绿/黑/白色板，颜色贯通预览与最终导出（原固定红色）。
- **改进：上传画质四档 → 五档**：原图（原始尺寸）/ 高（2048px 超精细细节）/ 中（1280px，**默认改为中档**）/ 低（960px，约 130KB）/ 极低（320px 细节不可辨认）；已保存的旧档位选择自动按新参数生效，无需重新设置。
- **修复：有标注内容时旋转直接清空无提示**——现在先弹「清除标注并旋转?」确认框，空画面旋转不弹窗。
- **修复：Gitee `releases/latest` 端点"最近编辑"陷阱**（双端三处：App `update_check`、host `apk-link`、host `update-check` 改用 releases 列表端点 + 客户端版本比较取最高 tag）。此前在 Gitee 网页上编辑/改名任何老发行版都会让 App 误判"已是最新版本"、二维码指向旧 APK，三处全部中招；现摆脱对该端点语义的依赖。

## 1.1.4（2026-11-03）

- **新增：推流画质四档可调（App 端）**。设置 → 拍摄与上传 → 推流画质：极低（320P 8fps）/ 低（480P 10fps）/ 中（默认，640P 10fps，与升级前取景画质一致，跟随电脑端下发参数）/ 高（720P 10fps）。仅影响电脑端实时取景，不影响拍摄照片画质（照片仍由"上传画质"决定）；切换下一帧即生效，无需重启预览或重连；帧协议不变（裸 JPEG 二进制），host 与 Web UI 零改动，新老版本双向兼容，无需版本门槛。推流画质存独立档位键，不被电脑端下发的预览参数在重连时覆盖（"中"档则严格采用下发值）。
- **修复：会话追踪数据面与宿主真实状态脱节（热重载补漏）**。`agent/created` 只在 agent 创建瞬间派发一次（无回放，cordis 事件无 retain），插件（重）加载晚于会话创建时内部存活表/活跃目标为空。现在声明 `agents` 服务依赖，服务就绪后枚举 `ctx.agents.list()` 回填：运行中的会话立即成为投递目标（与 `agent/status`→running 同语义），空闲会话进入存活表（pinned 目标模式可解析）；无 agents 服务的环境（standalone/dev）自动跳过，任何回填异常都不影响接收服务。
- devDependencies 对齐宿主实际运行版本并钉死精确版本（cordis 4.0.5、dsh-llm 0.2.1-rc.4、dsh-tools 0.2.1-rc.4、schemastery 3.18.5），类型参考与 0.2.1 一致；peerDependencies 范围不变。
- 文档勘误（docs/dsh-caps.md、docs/architecture.md）：移除对 0.1.7 已删除 `agent/session-start` 事件的引用；补记 live ctx 事件（`dsh-agent-loop` 派发）与持久会话日志事件（`agent/inbox/spliced`）的两层模型，防止按单包检索误判事件死活。

## 1.1.3（2026-10-16）

- **新增：前后置镜头切换（双端）**。手机端取景器右上角新增镜头切换按钮（单摄设备自动隐藏，切换中转圈）；电脑端新增模型工具 `phone_camera_lens`——`lens` 传 "front"/"back" 切换镜头，不带参数查询当前镜头与设备可用镜头（工具对相机关闭的手机同样可用：仅记录偏好，下次开启生效）。需手机端 ≥ 1.1.3，沿用三档失败判定。
- **精简：`phone_camera_zoom_info` 并入 `phone_camera_zoom`**——不带参数调用 zoom 即查询当前倍数与支持范围（手机端早已支持，纯工具层冗余）；工具总数 7→6。`phone_camera_pause`/`resume` 审查后保留独立（反义动作直命名对模型更清晰）。
- **修复：悬浮面板弹出方向左右反了**——球靠左时面板向左弹出被屏幕裁掉（水平侧判定与锚点类语义相反），现已按"空间大的一侧展开"正确选择。

- **悬浮球可拖拽、可调大小**：按住悬浮球可拖到屏幕任意位置（自动限制在视口内，窗口缩放后自动收回）；设置页新增"悬浮球"分组——三档大小、四角停靠（左上/右上/左下/右下）、锁定位置防误拖、一键恢复默认。取景面板/重命名/下载码弹层会根据悬浮球位置与面板实际高度智能选择弹出方向（上下左右四向），弹出动效随之适配。
- **保存文件夹改为浏览选择**：拍照模式选"注入并保存/仅保存"后，目录输入旁新增"浏览…"按钮，弹出资源管理器式文件夹选择框（上级/主目录/盘符切换、逐级进入、选完即存）。手输/粘贴路径仍然可用。浏览器网页拿不到系统目录选择对话框的绝对路径，故由接收端（loopback 专属接口）遍历目录树提供。
- **设置页重构**：官方设置页（设置 → PhoneLens）整理为三张卡片——"模型相机工具"（启用/免确认开关 + 工具清单说明）、"悬浮球"、"连接"。接收端口从悬浮窗 ⚙ 面板移入设置页（保存即时生效，无需刷新）；悬浮窗 ⚙ 只保留高频的拍照模式与保存目录。
- **修复：变焦/暂停工具间歇误报"手机 App 版本过旧"**。手机 WS 重连后 host 端把相机元数据重置，而 App 版本只随预览流启动的 hello 上报——预览关闭或重连后的秒级窗口内，版本门槛读到空值，把正当版本的手机误判为过旧。现在失败原因分三档（没有已连接的手机 / 刚重连握手尚未完成 / 真版本不足），门槛检查前短暂等待（≤1 秒），App 端连接建立即上报版本（新 `app_info` 消息，不再绑定预览流启动）。
- **安全：HTTP 与 WebSocket 全面校验 Host 头（DNS rebinding 防护）**。合法客户端一律以 IP 字面量或 localhost 访问，域名形式或缺失的 Host 头一律 403 拒绝。
- 补齐 CHANGELOG（0.3.6 起此前全部缺失）。
