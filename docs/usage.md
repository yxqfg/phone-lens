# 使用说明

本页面向使用者，说明 PhoneLens 的日常操作与常见问题。进阶开发见仓库根 README。

## 一、连接与配对

1. 电脑端启动 dsh，跑一次接入后，终端会打印配对二维码。
2. 手机打开 **PhoneLens** → 扫码配对（**扫码新增配对**在设置 → 配对与设备）。
3. 无法扫码时，用「手动输入配对码」：`主机:端口:配对码`。
4. 配对码一次性，15 分钟有效；设备 token 只存哈希，重连免扫码。

## 二、拍照 / 实时取景

- **拍照**：取景页按白色快门 → （可选裁剪）→ 发送 → 图片进入当前 dsh 会话，模型下一轮直接看到。
- **实时取景**：取景页点「启动预览」→ 电脑端悬浮小窗 / 独立取景页显示实时画面。
- 双端任一快门都走同一条上传 → 注入管线。

## 三、多设备

- 多台手机可同时配对。
- **手机端「设为主机」**：一键把电脑端预览切换到本机（其他设备自动暂停推流）。
- 电脑端小窗也可切换预览、双击设备名重命名。
- 未选中的手机暂停推流，但仍可上传图片。

## 四、裁剪与批量

- 设置 → 裁剪：默认框选范围、手柄大小可调。
- 裁剪页可用「旋转 90°」，裁剪框不会超出图片，点 ✕ 即丢弃。
- **批量裁剪**：从相册多选开启裁剪后，会逐张连续裁剪（「下一张 → 上传 → 下一张」）；中途点 ✕ 丢弃剩余全部。

## 五、颜色 / 对焦

- **取景对焦**（设置 → 画面）：开启后可点击对焦、长按锁定对焦；关闭则用相机自动对焦。
- **颜色校正（红蓝互换）**：预览出现红/蓝颠倒、肤色失真时开启。

## 六、常见问题

**配不上对**
- 确认手机与电脑在同一局域网；重新扫码（配对码过期可点「刷新」）。

**预览无画面**
- 检查手机「启动预览」是否开启、接收服务（8791）是否运行；多设备时点「设为主机」或到电脑端选中本机。

**颜色异常**
- 设置 → 画面 → 打开「颜色校正（红蓝互换）」。

**连不上 / 频繁断开**
- 确认防火墙放行了 8791（仅私有网段，见 `scripts/firewall.ps1`）；手机与电脑用同一 Wi-Fi 或 USB 共享网络。

**本机提示「暂停推流」**
- 另一台手机正占用电脑端预览；本机仍可上传，点「设为主机」即切回本机。

**换网络后连不上**
- 开启「设置 → 配对与设备 → 自动选择可用连接」，或手动点选另一台已配对电脑激活。

**「已保存到电脑 ✓（暂未注入会话）」**
- 图片已落盘，只是当前没有进行中的 dsh 会话（或尚未接入 dsh），不是错误。
